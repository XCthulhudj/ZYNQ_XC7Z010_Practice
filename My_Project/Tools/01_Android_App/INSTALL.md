# 远程开关MQTT · 使用说明

**当前版本 v1.4** · 安装包：`RemoteSwitchMQTT_v1.4.apk`（53 KB，Android 5.0 及以上）
配套设备：ESP8266 多路继电器开关通用固件 **V2.63**，**1 路**型号。

远程原理：设备主动连 MQTT 服务器，手机也连同一个服务器，双方在同一个「主题」上收发。
**家里不用公网 IP、不用端口映射**，手机用 4G/5G 或任何 WiFi 都能控制。

---

## 一、设备端配置（每台设备做一次，电脑上操作）

用 `02_Device_Docs` 里的网络参数设置工具（`3.网络参数设置V2.6.zip` 或 `8.设置工具V2.61.zip`）：

| 项目 | 填什么 |
|---|---|
| 工作模式 | **MQTT** |
| 服务器地址 | `broker.emqx.io` |
| 端口 | `1883`（**不要填 8883**，设备不支持 SSL） |
| 账号 / 密码 | 留空（公共测试服务器） |
| 订阅 / 发布主题 | **设备 ID**，例如 `8c4f0052013a` |

点「保存设置生效」，设备自动联网。**多台设备各自配好自己的主题即可，可以共用一个服务器。**

## 二、手机端：添加设备

装好 APK 打开 →「更多设置 → 我的设备 → ＋ 添加设备」，三个框：

| 字段 | 说明 |
|---|---|
| 名称 | 显示在顶部胶囊上，例如「客厅灯」 |
| 设备 ID | 配置工具里那个主题，例如 `8c4f0052013a`（必填） |
| 备注 | 写用途，例如「一楼客厅吸顶灯 / 接路由电源」 |

点「添加并连接」，回到主界面就能用了。

### 多设备怎么用

- 主界面顶部一排胶囊就是设备列表，**点一下就切过去**（自动换主题重连）。
- **长按胶囊**：编辑名称/备注、切换、删除。
- 添加、改名、改备注、删除在「设置 → 我的设备」里也能做，每行都有「编辑 / 删除」。
- **会记住**：设备列表和最后选中的那台都存在手机里，下次打开自动连上次那台，不用重新填。
- 删除旧设备：设置里每行的「删除」，或长按胶囊选删除。只从手机列表移除，不影响设备本身。

### 自动搜索设备（能搜到就用，搜不到手动加）

设置里有个「自动搜索设备（10 秒）」：临时监听服务器 10 秒，把**看起来像本固件回包**的主题列出来，点一下就加入列表。

**为什么经常搜不到**：这套固件只在收到指令时才往自己的主题发消息，**不会主动广播**，
所以只有「正在通信」的设备（比如你刚在它上面点过、或别的手机正在控它）才会被看到。
而且公共服务器上还有其他人的流量，搜索时有噪声。
**最稳的方式永远是：手动填设备 ID 添加**（ID 在配置工具里能直接复制）。

## 三、界面

**主界面**

| 区域 | 作用 |
|---|---|
| 顶部 | 应用名 + 当前设备（名称 · 备注）+ 在线状态（绿点在线 / 黄点连接中 / 灰未连接） |
| 设备胶囊条 | 多设备切换，右边「＋ 添加」 |
| 状态卡 | 大字「已导通 / 已断开」，下面信号强度和时间；大按钮一键开关 |
| 快捷操作 | 点动 1 秒 / 0.6 秒 / 自定义 N 秒 |
| 设备信息 | 设备 ID、固件版本、WiFi 名、内网 IP、上电模式、面板锁（右上「刷新」） |

**设置页**

| 区域 | 作用 |
|---|---|
| 我的设备 | 设备列表（点击切换、编辑、删除）、添加设备、自动搜索 |
| MQTT 服务器 | 地址 / 端口 / 账号 / 密码、保存并连接、断开、断线自动重连 |
| 设备设置 | 上电全关/全开/断电记忆、锁定/解锁面板、开/关配网、重启设备（对当前设备） |
| 开发者选项（默认折叠） | 收发日志、发送任意指令、崩溃记录、版本信息 |

## 五、排障

| 现象 | 处理 |
|---|---|
| 顶部一直「未连接」 | 手机能不能上网；公司网络可能封 1883；先在设置里点「保存并连接」看日志 |
| 在线但设备没反应 | 主题（设备 ID）和设备端不一致，区分大小写 |
| 搜不到设备 | 正常现象，见上面说明；手动填 ID |
| 设备重启后掉线 | 等 10–30 秒，开了自动重连会自己连回来 |
| 切设备后状态是「未知」 | 正常，切过去会重新查一次；点「刷新」 |
| 出问题了要日志 | 设置 → 开发者选项 → 收发日志 / 崩溃记录，可复制 |

## 六、安全提醒

`broker.emqx.io` 是公开测试服务器，**知道主题的人都能控制**。
长期使用建议自建 EMQX（NAS / 树莓派 / 云主机都行），设备端和 APP 里都填账号密码，
主题换成别人猜不到的字符串。设备不支持 SSL，自建也只需开明文 1883。
