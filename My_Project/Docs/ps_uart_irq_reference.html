一串口 UART 初始化函数

头文件：#include "xuartps.h"

函数作用备注
XUartPs_LookupConfig()获取 UART 配置信息SDT BSP 传的是基地址
XUartPs_CfgInitialize()初始化 UART 驱动实例传 Config + BaseAddress
XUartPs_SelfTest()UART 自检可选，学习阶段可跳过
XUartPs_SetOperMode()设置工作模式常驻 XUARTPS_OPER_MODE_NORMAL
XUartPs_SetBaudRate()设置波特率返回 s32，0 表示成功
XUartPs_SetFifoThreshold()设置接收 FIFO 触发阈值决定 RXOVR 何时触发
XUartPs_SetInterruptMask()设置中断屏蔽寄存器（IER/IDR）使能 / 关闭中断源

常见初始化流程：

UartConfig = XUartPs_LookupConfig(UART_ID);

XUartPs_CfgInitialize(&UartInstance, UartConfig, UartConfig->BaseAddress);

XUartPs_SetOperMode(&UartInstance, XUARTPS_OPER_MODE_NORMAL);
XUartPs_SetBaudRate(&UartInstance, 115200);
XUartPs_SetFifoThreshold(&UartInstance, 1);
注意Vitis 2025.1 的 SDT BSP 里，XUartPs_LookupConfig() 的参数是 基地址（如 XPAR_XUARTPS_0_BASEADDR），不是 DEVICE_ID。 沿用时请注意和自己 BSP 的版本对齐。

二GIC 中断控制器函数

头文件：#include "xscugic.h"。GIC 负责把 CPU 收到的各种中断请求汇总、判优、分发。

函数作用
XScuGic_LookupConfig()获取 GIC 配置信息
XScuGic_CfgInitialize()初始化 GIC
XScuGic_Connect()将中断 ID 与中断服务函数绑定
XScuGic_Enable()使能指定中断（允许转发到 CPU）
XScuGic_Disable()禁止指定中断
XScuGic_Disconnect()解除中断服务函数绑定
XScuGic_SetPriorityTriggerType()设置中断优先级和触发类型
GicConfig = XScuGic_LookupConfig(INTC_ID);

XScuGic_CfgInitialize(&GicInstance, GicConfig, GicConfig->CpuBaseAddress);

三CPU 异常与中断注册函数

头文件：#include "xil_exception.h"

函数作用
Xil_ExceptionInit()初始化异常处理机制
Xil_ExceptionRegisterHandler()注册 CPU 异常处理函数
Xil_ExceptionEnable()开启 CPU 全局异常响应（IRQ）
Xil_ExceptionDisable()关闭 CPU 全局异常响应
Xil_ExceptionInit();

Xil_ExceptionRegisterHandler(XIL_EXCEPTION_ID_INT,
                             (Xil_ExceptionHandler)XScuGic_InterruptHandler,
                             &GicInstance);

Xil_ExceptionEnable();
两个 handler 别混了 XScuGic_InterruptHandler 是 GIC 提供的通用分发函数，挂在 CPU 异常向量上； uart_intr_handler 是你自己写的 UART 中断服务函数，由 XScuGic_Connect() 挂到具体的中断号上。

四UART 中断相关宏

主要来自 #include "xuartps.h"（实现在 xuartps_hw.h）。

宏位值含义
XUARTPS_IXR_RXOVR00x0001接收 FIFO 达到触发阈值
XUARTPS_IXR_RXEMPTY10x0002接收 FIFO 空
XUARTPS_IXR_RXFULL20x0004接收 FIFO 满
XUARTPS_IXR_TXEMPTY30x0008发送 FIFO 空
XUARTPS_IXR_TXFULL40x0010发送 FIFO 满
XUARTPS_IXR_OVER50x0020接收 FIFO 溢出错误
XUARTPS_IXR_FRAMING60x0040帧错误
XUARTPS_IXR_PARITY70x0080奇偶校验错误
XUARTPS_IXR_TOUT80x0100接收超时
XUARTPS_IXR_DMS90x0200Modem 状态变化
XUARTPS_IXR_TTRIG100x0400发送 FIFO 触发
XUARTPS_IXR_TNFUL110x0800发送 FIFO 接近满
XUARTPS_IXR_TOVR120x1000发送 FIFO 溢出
XUARTPS_IXR_RBRK130x2000接收线路 Break 检测

常用的接收中断使能：

XUartPs_SetInterruptMask(&UartInstance, XUARTPS_IXR_RXOVR);
易误解XUARTPS_IXR_RXOVR 不是"接收数据溢出错误"， 而是接收 FIFO 触发阈值中断（fill level ≥ 阈值就报）；真正表示接收溢出错误的是 XUARTPS_IXR_OVER（0x0020）。

工作模式宏（XUartPs_SetOperMode() 用）：

宏值含义
XUARTPS_OPER_MODE_NORMAL0x00正常收发
XUARTPS_OPER_MODE_AUTO_ECHO0x01自动回显
XUARTPS_OPER_MODE_LOCAL_LOOP0x02本地自环（不发到引脚）
XUARTPS_OPER_MODE_REMOTE_LOOP0x03远端自环（经 IO 收发）

五UART 寄存器操作宏

偏移量定义在 xuartps_hw.h，读写用 XUartPs_ReadReg() / XUartPs_WriteReg() 这两个宏（BaseAddress，不是实例指针）。

宏偏移含义
XUARTPS_IER_OFFSET0x08中断使能寄存器（写 1 使能）
XUARTPS_IDR_OFFSET0x0C中断禁止寄存器（写 1 禁止）
XUARTPS_IMR_OFFSET0x10中断屏蔽寄存器（读回当前使能）
XUARTPS_ISR_OFFSET0x14中断状态寄存器（写 1 清除）
XUARTPS_SR_OFFSET0x2C通道状态寄存器（RXEMPTY / TXFULL 等）
XUartPs_ReadReg(BaseAddress, RegisterOffset);
XUartPs_WriteReg(BaseAddress, RegisterOffset, RegisterValue);

例如读状态寄存器：

u32 status;

status = XUartPs_ReadReg(UartInstance.Config.BaseAddress, XUARTPS_SR_OFFSET);

六中断服务函数中的收发函数

函数作用参数
XUartPs_RecvByte()接收一个字节基地址
XUartPs_SendByte()发送一个字节基地址 + 数据
XUartPs_Recv()接收多个字节（驱动缓冲 + 中断驱动）实例指针
XUartPs_Send()发送多个字节（驱动缓冲 + 中断驱动）实例指针
XUartPs_GetInterruptMask()获取当前中断屏蔽配置实例指针
u8 data;

data = XUartPs_RecvByte(UART_BASEADDR);
XUartPs_SendByte(UART_BASEADDR, data);
两套 API 的区别 RecvByte()/SendByte() 是硬件层单字节操作，收 BaseAddress，在自写 ISR 里最直接； Recv()/Send() 是驱动层带缓冲的批量收发，收 实例指针，需要配合驱动自带中断分发 （XUartPs_SetRecvHandler() / XUartPs_SetSendHandler() + XUartPs_InterruptHandler）才工作。学习阶段建议先用前者。

七完整的中断处理流程

  1. UART 初始化　LookupConfig / CfgInitialize / SetBaudRate / SetFifoThreshold
  2. GIC 初始化　XScuGic_LookupConfig / XScuGic_CfgInitialize
  3. CPU 异常初始化　Xil_ExceptionInit / RegisterHandler / Enable
  4. 注册 UART 中断服务函数　XScuGic_Connect(UART_INTR_ID, uart_intr_handler, …)
  5. 使能中断　XUartPs_SetInterruptMask(RXOVR) + XScuGic_Enable(UART_INTR_ID)
  6. UART 收到数据 → 产生中断　UART 置 ISR → GIC 判优 → CPU 进入 IRQ
  7. 执行 uart_intr_handler()　读状态 → 取数据 → 清中断 → 处理数据
RX FIFO 达阈值→ UART ISR bit0→ GIC 转发 IRQ→ XScuGic_InterruptHandler→ uart_intr_handler→ 读 FIFO / 清 ISR

ISR 里清中断的写法（Zynq UART 的 ISR 是 写 1 清除）：

u32 isr = XUartPs_ReadReg(UART_BASEADDR, XUARTPS_ISR_OFFSET);

XUartPs_WriteReg(UART_BASEADDR, XUARTPS_ISR_OFFSET, isr);   /* 写 1 清对应位 */

八最值得记住的函数清单

学中断机制时，按这个顺序掌握即可打通链路：

优先级函数核心作用
1XScuGic_CfgInitialize()初始化 GIC
2Xil_ExceptionRegisterHandler()注册 CPU 中断分发函数
3XScuGic_Connect()注册具体中断服务函数
4XScuGic_Enable()使能 GIC 中断
5XUartPs_SetInterruptMask()使能 UART 中断源
6XUartPs_RecvByte()接收数据
7XUartPs_SendByte()发送数据
8XUartPs_ReadReg()读 UART 寄存器
9XUartPs_WriteReg()写 UART 寄存器
两个"使能"必须都做 XUartPs_SetInterruptMask() 只是让 UART 外设产生中断请求； XScuGic_Enable() 才是让 GIC 把该中断转发给 CPU。 少任何一个，中断链路都不通——排查"进不去 ISR"时先看这两处。

九一处值得改进的地方

原来的写法里，XUartPs_RecvByte() 一次只取一个字节。如果一次收到多字节 （比如机械臂主从控制的命令帧），剩下的字节还留在 FIFO 里，处理效率低、也容易被后续数据挤掉。 建议在 ISR 里循环读到 FIFO 空，再统一处理：

static void uart_intr_handler(void *arg)
{
    XUartPs *uart = (XUartPs *)arg;
    u32 base = uart->Config.BaseAddress;
    u32 isr  = XUartPs_ReadReg(base, XUARTPS_ISR_OFFSET);

    if (isr & XUARTPS_IXR_RXOVR) {
        /* 循环读空 RX FIFO，一次把所有字节取走 */
        while ((XUartPs_ReadReg(base, XUARTPS_SR_OFFSET) &
                XUARTPS_SR_RXEMPTY) == 0U) {
            if (rx_len < sizeof(rx_buf)) {
                rx_buf[rx_len++] = XUartPs_RecvByte(base);
            } else {
                (void)XUartPs_RecvByte(base);      /* 溢出保护：丢弃 */
            }
        }
        frame_ready = 1;                            /* 交给 main 解析 */
        XUartPs_WriteReg(base, XUARTPS_ISR_OFFSET, XUARTPS_IXR_RXOVR);
    }
}
补充把阈值设成 1（XUartPs_SetFifoThreshold(&uart, 1)）时，每来一个字节就进一次 中断，循环体通常只跑一轮；等以后把阈值调大（如 16）做批量传输，这段循环就能显著减少中断次数。

附校对说明（对照 uartps v3.16 源码）

原清单中的写法uartps v3.16 里的实际情况
XUARTPS_IXR_MODEM 不存在这个宏；对应的是 XUARTPS_IXR_DMS（0x0200，Modem 状态变化）
XUARTPS_IXR_TXOVR 应为 XUARTPS_IXR_TOVR（0x1000）；"接收溢出错误"是 XUARTPS_IXR_OVER（0x0020）
XUARTPS_IXR_RXEMPTY 有效位（0x0002），但含义是"RX FIFO 空"，一般不单独使能它做数据接收
XUARTPS_IXR_RXOVR 确认是 RX FIFO 触发中断，不是溢出——原文这一点是对的

另外：有效中断位掩码是 XUARTPS_IXR_MASK（0x3FFF，bit0~13）； XScuGic_Connect() 里 UART 的中断号来自 xparameters_ps.h： XPAR_XUARTPS_0_INTR = XPS_UART0_INT_ID = 59（基地址 0xE000_0000）， XPAR_XUARTPS_1_INTR = XPS_UART1_INT_ID = 82（基地址 0xE000_1000）。

依据：Vitis 2025.1 · standalone (SDT) BSP · uartps_v3_16 与 xscugic 驱动头文件； 中断 ID 取自 xparameters_ps.h。示例代码为教学用最小实现，未包含去抖 / 帧解析 / 错误统计。
